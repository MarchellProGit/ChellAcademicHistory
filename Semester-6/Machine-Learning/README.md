## Domain Overview & Technical Specifications

This directory houses supervised and unsupervised machine learning algorithms, model evaluation suites, and clustering pipelines developed using Python, `scikit-learn`, `pandas`, `numpy`, and `matplotlib`.

### Pipeline Architecture

```text
Semester-6/Machine-Learning/
 notebooks/
 Clustering - DBSCAN.ipynb # Density-Based Spatial Clustering with Noise
 Clustering - KMEANS.ipynb # Centroid K-Means Clustering & Elbow Method Analysis
 klustering.ipynb # Comparative Silhouette Score & Hierarchical Clustering
 latihan_regresi.ipynb # Linear & Polynomial Regression Analysis
 klasifikasi.ipynb # Decision Trees, Random Forest & Support Vector Machines
 Classification_Logistic_Regression_Pipeline.ipynb # Binary Classification & Logistic Curves
 Supervised_Learning_Model_Evaluation.ipynb # Confusion Matrix, ROC-AUC Curves & Cross-Validation
```

---

## Modules Breakdown

| Module / Notebook | Primary Techniques | Input Dataset | Output / Evaluation Metrics |
| :--- | :--- | :--- | :--- |
| `Clustering - KMEANS.ipynb` | K-Means Centroid Initialization | Synthetic & Real 2D Feature Vectors | Inertia Scores, Elbow Curves |
| `Clustering - DBSCAN.ipynb` | Epsilon Density Search | Non-linearly Separable Datasets | Noise Identification, Cluster Core Points |
| `Classification_Logistic_Regression_Pipeline.ipynb` | Logistic Regression, Sigmoid Mapping | Binary Classification Target Vector | Precision, Recall, F1-Score |
| `Supervised_Learning_Model_Evaluation.ipynb` | Stratified K-Fold Cross-Validation | Multi-feature Classification Matrix | Confusion Matrix, ROC-AUC Curve |
