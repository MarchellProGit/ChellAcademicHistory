## Project Overview

This repository contains the **Tugas Rancang Capstone Project** for the *Interaksi Manusia dan Komputer* course. It is an interactive, high-fidelity UI/UX prototype for **PayJek**, an on-demand super-app featuring food delivery, driver interfaces, payment flows, and user account management.

---

## Architecture & UI Layout

```text
Interaksi-Manusia-dan-Komputer/
 README.md # Course documentation
 Tugas-Rancang-PayJek-UI/
 index.html # Landing & hero showcase page
 beranda.html # Main user dashboard
 beranda_login.html # Authenticated user dashboard
 sign_in.html & sign_up.html # User authentication flows
 delivery.html # On-demand delivery service interface
 Food.html # Food ordering & restaurant catalog
 payjek.html # E-wallet & transaction portal
 aboutus.html # About platform & team
 help.html & privasi.html # Help center & privacy policy
 driver/ # Driver App UI Interfaces (driver1..driver7)
 css/ # Custom stylesheets & vector icons
```

## How to Run

Open `index.html` in any modern web browser or run via local HTTP server:

```bash
python -m http.server 8000
```
Navigate to `http://localhost:8000`.
