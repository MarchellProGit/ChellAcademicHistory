## 📌 Project Overview

This repository contains the **Tugas Rancang (Final Capstone Project)** for the *Pengantar Teknologi Informasi* course. It is a multi-page responsive personal web portfolio showcasing academic achievements, student profile, personal passions/hobbies, and contact channels.

---

```text
Tugas-Rancang/

├── portfolio.html          # Main Web Portfolio Showcase
├── about.html              # Academic Profile & Student Credentials
├── hobbies.html            # Passions, Music & Personal Pursuits
```

## 🚀 Key Features

* **Multi-Page Navigation**: Seamless routing between Welcome portal, Portfolio showcase, Academic Bio, Hobbies, and Social Contact.
* **Responsive Bootstrap Layout**: Mobile-friendly navigation bar, grid layouts, and card components.
* **Custom Styling**: Glassmorphism cards, glowing headers, and dark-theme aesthetics.

## 🖥️ How to Run

Simply open `index.html` in any modern web browser or serve via Live Server / local HTTP server:

```bash
# Option 1: Double click index.html
# Option 2: Live Server via Python
python -m http.server 8000
```
Then navigate to `http://localhost:8000`.
